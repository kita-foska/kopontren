Tutorial W15-P2a: Kotak Pintar Kini Bisa Menjumlahkan + Tautan Langsung

Untuk siapa: kasir, manajer, dan admin. Tidak perlu paham teknologi -- cukup baca dari atas ke bawah. Dua fitur baru di Kotak Pintar (tombol kaca, di atas layar, atau tekan Ctrl+K): kalkulator langsung dan tautan langsung ke hasil pencarian.

1. Hitung Langsung: 25000 x 12 = 300.000

Di layar Kasir (/pos), ketik ekspresi hitungan di Kotak Pintar. Hasilnya muncul seketika di bawah kotak -- tanpa meninggalkan layar kasir.

Pintar -- ketik apa saja...  25000 * 12
Kalkulator: 25000 * 12 = 300.000  (tekan Enter agar hasilnya jadi kata kunci lanjutan)
Apa yang boleh diketik: penjumlahan +, pengurangan -, perkalian * (atau tanda x), pembagian / (atau ÷), kurung ( ), persen 50%, koma dan titik desimal, tanda kurung siku dan kurung kurawal otomatis dibersihkan. Tanda = dan spasi boleh.
Tidak didukung (aman, tidak akan crash): input super panjang lebih dari 64 karakter, kurung tak seimbang, pembagian dengan 0, angka melampaui batas, huruf di tengah ekspresi.

Ketik tanda x juga berfungsi sebagai perkalian (mis. 25000x12), sesuai kebiasaan mengetik cepat.

3. Tautan Langsung: Bagikan Hasil Pencarian (Tanpa Login Ulang Cari)

Kini hasil pencarian bisa dibagikan lewat tautan. Tiga layar mendukung ?q=:

LayarTautan contohPerilaku
Manajemen > Produk
/admin/produk		 /admin/produk?q=Prada Kotak cari langsung terisi "Prada" -- daftar produk menyaring seketika.
Manajemen > Anggota
/admin/member		 /admin/member?q=Iqbal Sama -- terisi kata kunci anggota.
Kasir
/pos		 /pos?q=Prada Kotak terisi "Prada"; jika ada SATU produk yang cocok persis (nama atau barcode), produk itu ditalik otomatis ke troli -- setara tekan Enter sekali. Lebih dari satu cocok = hanya terisi, kasir pilih sendiri (aman, tidak salah talik).
Bagaimana cara membuktakannya: salin tautan di atas, tempel ke browser, buka link -- kotak pencarian di layar target langsung berisi kata kunci. Tautan ini berguna untuk berbagi "cari barang X" antar kasir tanpa harus mengetik ulang.

4. Keamanan (Tidak Perlu Diingat, Cukup Tahu)

Hitungan dikerjakan langsung di perangkat (tanpa dikirim ke server). Input aneh (huruf di tengah, kurung tak seimbang, input raksasa) dibuang diam-diam -- tidak akan merusak aplikasi. Tidak ada perubahan skema, tidak ada data baru.

Rangkuman

(1) Ketik 25000 * 12 di Kotak Pintar = hasil 300.000 seketika. (2) Tautan /pos?q=... / /admin/produk?q=... / /admin/member?q=... mengisi kotak cari -- di Kasir, cocok persis = talik otomatis. (3) Semua aman: tanpa server, tanpa crash.
