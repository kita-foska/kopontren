Tutorial W15-P2b: Tombol "Berripple" + Badge Troli "Melompat"

Untuk siapa: semua pengguna (kasir, manajer, admin). Tidak ada langkah baru dan tidak ada tombol baru -- yang berubah hanya rasa saat memakainya: tombol kini menampilkan efek kecil (ripple) saat ditekan, dan badge jumlah item di keranjang kasir "melompat" pendek setiap ada item baru ditambahkan.

1. Efek Ripple di Tombol

Saat menekan tombol mana pun di aplikasi, muncul lingkaran kecil yang menyebar dari tengah tombol -- memberi konfirmasi visual "kebenaran tombol didengar". Ini berlaku untuk semua tombol di aplikasi (tombol maroon, tombol sekunder, tombol ikon, dsb).

Saat sentuh di HP efeknya terasa jelas: layar sentuh tidak punya "warna tombol berubah" setajam mouse, maka ripple menjadi umpan balik sentuhan yang halus.

2. Badge Troli "Melompat"

Di layar Kasir, angka item di bagian atas Keranjang (mis. "3 item") kini melompat pendek setiap berubah -- menandai kasir bahwa keranjang baru saja bertambah tanpa harus memperhatikan terus.

3. Pengaturan Gerak Terbatas (Reduced Motion)

Jika perangkat Anda memakai pengaturan "Kurangi animasi" (Windows: Ease my motion; HP biasanya di menu aksesibilitas), kedua efek ini matikan sendiri -- tombol tetap berfungsi normal, hanya tanpa animasi. Tidak perlu diubah apa pun.

Rangkuman

(1) Semua tombol kini berripple saat ditekan. (2) Badge jumlah item keranjang kasir melompat setiap berubah. (3) Jika perangkatnya memakai "kurangi animasi", semuanya otomatis mati -- fungsi tidak berubah. Tidak ada data atau skema yang disentuh.
