Tutorial W16-C: Alat Ukur Kecepatan Aplikasi

Untuk siapa: semua pengguna (kasir, pengurus, admin). Tidak ada tombol baru dan tidak ada layar baru. Yang berubah: kini kecepatan aplikasi dapat diukur sendiri dengan satu perintah, dan ada "alat detak" di dalam aplikasi yang mencatat kecepatan pemakaian nyata. Sebagai bonus terukur, font aplikasi diuji dua gaya dan terbukti gaya lama (swap) memang terhebat -- maka tetap dipakai. Tampilan dan data Anda tidak berubah sama sekali.

1. Apa yang berubah?

NoPerubahanYang Anda rasakan
1 Alat ukur kecepatan (Lighthouse): satu perintah npm run lighthouse:mobile menguji aplikasi seperti ponsel (layar, sinyal, CPU ponsel), lalu memberi nilai 0--100 dan catatan detail. Hasil tersimpan di folder artifacts/ (folder kerja lokal, tidak ikut terkirim ke repositori). Tidak terasa langsung -- ini alat tukang: bila suatu hari aplikasi terasa melambat, penyebabnya dapat diukur, bukan ditebak.
2 Pencatat kecepatan di dalam aplikasi: versi produksi kini mencatat lima angka nyata saat dipakai: ketajaman halaman (CLS), muncul pertama (FCP), gambar/teks utama (LCP), tanggapan tombol (INP), dan jawaban server (TTFB). Angka tampil di konsol pengembang (Developer Tools) saat aplikasi berjalan -- tidak di layar aplikasi. Tidak terlihat pengguna -- ini "alat detak" untuk memantau bahwa aplikasi tetap responsif di dunia nyata, termasuk di HP kasir.
3 Font diuji dua gaya: gaya swap (tampilkan dulu font saku, ganti seketika saat font resmi selesai diunduh) dibanding gaya optional (ganti hanya bila font resmi tiba tepat waktu). Hasil: gaya swap membuat tombol lebih gesit (waktu tombol tersendat 50 ms vs 110 ms) dan nilai performa sedikit lebih tinggi (98 vs 97). Maka swap dipertahankan. Tes ketukan kasir (pilih produk, hitung) terasa gesit -- terutama di sinyal lemah. Tampilan tidak berubah.

2. Hasil ukurannya (gambarnya)

Nilai lengkap hasil uji swap: Performa 98 dari 100, Aksesibilitas 94, Praktik Terbaik 100, SEO 92; halaman pertama tampil 1,2 detik, halaman stabil tanpa lompat-lompat (CLS 0), tombol gesit (tersendat 50 milidetik).

HalStatus

File beku proyek (service worker, POS, laporan, rekap) Tidak berubah -- diverifikasi sebelum commit.

4. Pertanyaan yang sering

PertanyaanJawaban
Kapan angka "alat detak" itu terlihat? Hanya di versi produksi, lewat Developer Tools (konsol). Saat development angka itu tidak dicatat, agar tidak mengotori layar kerja.
Nilai 98 ini dibanding nilai 58 versi online (Vercel)? Tidak langsung sebanding: 98 diukur di komputer sendiri (tanpa jarak jaringan), 58 diukur di Vercel. Keduanya valid di lingkungannya masing-masing; keputusan proyek memutuskan tidak perlu mengukur ulang di Vercel.
Apa yang perlu Anda lakukan? Tidak ada. Semua berjalan otomatis di belakang layar.

Ringkasnya: aplikasi kini bisa diukur kecepatannya sendiri dengan satu perintah, pemakaiannya nyata dicatat oleh "alat detak" versi produksi, dan font terbukti terbaik dengan gaya swap. Tampilan, data, dan semua fitur tetap seperti semula.
