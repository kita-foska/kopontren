Tutorial W14-1 — e-Struk Interaktif (Link Publik)

Kopontren App · 26 Okt 2026 · untuk Gus Fi (penjelasan dari nol, tanpa istilah)

1. Apa yang baru?

Sebelumnya, struk hanya bisa cetak, salin teks, kirim file dari HP kasir. Sekarang kasir punya tombol “Bagikan Link”: satu tautan unik per transaksi yang bisa dibuka pembeli langsung di HP-nya, tanpa harus login, tanpa harus bikin akun. Pembeli melihat struk bergaya m-banking (bersih, rapi, ada logo) dan bisa Unduh PDF / Unduh Foto / Kirim WA / Salin Teks.

Forma link-nya seperti ini (contoh): 

https://kopontren.app/struk/123.aB3fG7Kp9Q2zX1Cw
                              ^^^  ^^^^^^^^^^^^^^
                          ID transaksi   tanda rahasia (HMAC, tidak bisa ditebak)

Nomor urut transaksi memang mudah diketahui orang (1, 2, 3…), tapi bagian tanda rahasia-nya hanya bisa dibuat oleh sistem karena memakai kunci rahasia server (STRUK_LINK_SECRET). Jadi orang tak bisa “menebak-nebak” link transaksi lain. Ini pilihan keputusan Gus Fi O1: Publik + HMAC.

2. Cara pakai (Kasir)

  1. Transaksi selesai — muncul jendela “Transaksi Disimpan” (sama seperti biasa).
  2. Tekan tombol Bagikan Link (di sebelah “Unduh Foto”).
  3. Ponsel: muncul menu bagikan — pilih WhatsApp. Desktop: link otomatis disalin — tempel ke chat.
  4. Pembeli buka link di HP-nya — struk tampil. Tombol di bawahnya untuk mengunduh/mengirim.

3. Sekali saja: kunci rahasia di server (Vercel)

Fitur ini baru “hidup” setelah kunci rahasia diisi. Kuncinya = STRUK_LINK_SECRET — teks acak minimal 16 karakter (sebaiknya 64 karakter, seperti kunci gembok digital). Kuncinya disimpan di server saja (bukan di kode, bukan di HP) — karena server adalah “pengepul” resmi tanda rahasia.

  1. Buka Vercel → proyek kopontren → Settings → Environment Variables.
  2. Isi nama STRUK_LINK_SECRET, nilai = teks acak 64 karakter (bisa dibuat di situs pembangkit kata acak, atau minta Cline membuatkan).
  3. Simpan — Vercel deploy ulang otomatis.

Jika belum diisi (kosong): tombol “Bagikan Link” tetap ada, tapi menampilkan pesan “e-Struk link belum dikonfigurasi”. Fitur lain (cetak, PDF, WA) tidak terpengaruh sama sekali. Kunci lokal di PC (file .env) sudah diisi otomatis oleh Cline — jadi di PC langsung jalan; di Vercel perlu diisi manual (langkah di atas).

5. Tanya-jawab (gaya awam)

Pembeli harus punya akun?
Tidak. Link-nya seperti tautan undangan pesta: yang memegang tautannya bisa masuk. Tidak perlu login apa-apa.

Link-nya bisa dicuri orang dan ditukar?
Tidak. Setiap link berisi “tanda tangan” (HMAC) yang hanya server yang bisa memalsukannya — seperti cap kawat pada resi. Link transaksi lain tak bisa dipakai di transaksi ini.

Link-nya ada masa kedaluwarsanya?
Link hidup selama transaksi masih ada di database (default tak ada batas waktu). Bila suatu saat data transaksi dihapus, link menampilkan “Transaksi tidak ditemukan” — aman, tak ada data bocor.

Bagaimana kalau kasir ingin membagikan ke dua orang?
Link yang sama boleh dibagikan ke siapa saja — itu memang maksudnya (bagi pembeli + anggota keluarga). Yang harus dijaga hanya jangan sampai kunci rahasia (STRUK_LINK_SECRET) bocor.

Apakah data struk dikirim ke mana-mana?
Tidak. Struk dibaca langsung dari database Kopontren; tak ada layanan pihak ketiga. Link hanya “jalan masuk”, bukan gudang.

6. Kenapa “HMAC”? (basa gampangnya)

Bayangkan resi kurir: nomor resinya singkat & mudah diketik (mudah diingat), tapi setiap resi punya kode verifikasi yang hanya diketahui perusahaan. HMAC = campuran keduanya: terbaca (ID transaksi) + rahasia (cap dari kunci server). Orang yang mengutak-atik capnya akan ketahuan karena server menghitung ulang capnya — beda sedikit saja, langsung ditolak.

7. Peta istilah

IstilahArtinya
e-StrukStruk elektronik berbentuk halaman web per transaksi
Link publikTautan yang bisa dibuka tanpa login (seperti undangan)
HMAC“Cap” keaslian: campuran nomor + kunci rahasia
STRUK_LINK_SECRETKunci rahasia server (kunci gembok digital), isi Vercel
DeterministikHasil selalu sama untuk input sama (link tak berubah-ubah)
Timing-safePembandingan dilakukan secepat rata-rata (tak bisa disusupkan info dari kecepatan)

8. Catatan penutup

Fitur ini memakai infrastruktur yang sudah ada (bukan bikin baru): PDF & foto struk dibuat dengan mesin yang sama dengan tombol “Unduh PDF/Foto” di POS (lib struk-media), teks WA memakai mesin rekap. Skema database tak diubah (tetap v34) — cuma “jalan masuk” (kunci + link) yang ditambah.
