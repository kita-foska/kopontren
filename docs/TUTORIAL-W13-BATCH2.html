1. Apa yang berubah?

Sebelumnya, notifikasi (dalam aplikasi dan push ke HP) hanya dikirim ke akun ber-peran admin. Sekarang dikirim ke 4 peran: admin, manajer, pengurus, kasir. Peran lain (member, gudang, pembelian) TIDAK menerima notifikasi — keputusan ini dipusatkan di satu modul kecil supaya konsisten.

4. Kenapa ada pesan “Install Aplikasi”?

Teknologi push di browser butuh aplikasi terpasang sebagai PWA (Progressive Web App). Kalau seseorang membuka dari browser biasa (bukan yang terpasang di layar beranda), teknologi push belum tersedia — maka tombol Aktifkan Push dinonaktifkan dan muncul kotak pesan kuning:

Web Push belum didukung di browser/perangkat ini. Untuk menerima notifikasi di HP, silakan Install Aplikasi (Add to Home Screen) terlebih dahulu: Chrome Android → menu “Install aplikasi”, atau iOS Safari → ikon Bagikan → “Ke Layar Beranda”. Setelah terpasang, buka ulang halaman ini.

Cara memasang PWA di HP:

  • Android (Chrome): buka situs → menu tiga titik → “Install aplikasi” / “Tambah ke layar utama”.
  • iOS (Safari): buka situs → ikon Bagikan (kotak panah ke atas) → “Ke Layar Beranda”.

Setelah terpasang, buka lagi /admin/notifications/settings → tombol Aktifkan Push menjadi aktif → browser minta izin → granted — mulai saat itu notifikasi masuk ke HP.

5. Pengaturan per orang (tetap individual)

Meskipun 4 peran menerima, setiap orang mengatur sendiri jenis apa yang mau muncul (in-app / push / keduanya). Nilai bawaan: in-app = ON, push = OFF. Jadi yang benar-benar menerima push di HP hanyalah mereka yang menekan “Aktifkan Push” — tidak spam.
