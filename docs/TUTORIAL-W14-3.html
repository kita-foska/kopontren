Tutorial: Health Meter / Spidometer Kesehatan Sistem (W14-3)

Untuk siapa: pengurus, manajer, dan admin yang membuka Dashboard Pengurus (layar /pengurus/dashboard). Tidak perlu paham teknologi apa pun -- cukup baca dari atas ke bawah.

Apa yang baru: di bagian atas dashboard kini tampil spidometer (health meter) -- seperti spidometer mobil. Jarumnya menunjuk skor 0 sampai 100 untuk kesehatan sistem: database, backup, dan notifikasi push. Di sebelahnya ada 3 baris rincian.

1. Membaca Spidometer

Warna Jarum / SkorMaknanya
Hijau (skor 90 ke atas)Sistem sehat. Tidak perlu tindakan apa pun.
Kuning/amber (skor 40-89)Ada hal yang perlu perhatian: mis. backup sudah lama belum diekspor, database agak lambat, atau push notifikasi belum diaktifkan. Lihat baris rincian di samping untuk tahu mana yang kuning.
Merah (skor di bawah 40)Ada gangguan: umumnya database tak terjangkau (skor langsung jatuh ke 30). Hubungi pengelola sistem / admin.

2. Tiga Baris Rincian di Samping Jarum

BarisYang Ditampilkan
DatabaseStatus koneksi database: OK (cepat), LAMBAT (perlu perhatian), atau GAGAL (tidak terjangkau). Angka di belakangnya = waktu respon dalam milidetik (mis. "42 ms" = sangat cepat).
BackupTanggal backup terakhir + berapa hari lalu + siapa yang mengekspor. Jika belum pernah ada backup, tampil BELUM berwarna kuning.
PushNotifikasi push (perangkat/browser) PUSH ON (kunci push sudah diset, normal) atau PUSH OFF (belum diset; notifikasi dalam aplikasi tetap jalan). Ditampilkan juga jumlah notifikasi tersimpan.

Titik warna di depan tiap baris: hijau = baik, kuning = perlu perhatian, merah = gangguan.

3. Tautan "Kesehatan Sistem" di Bawah Rincian

Baris kecil di bawah rincian adalah drill-down: tautan menuju halaman Kesehatan Sistem (menu admin) yang memuat 7 kartu lengkap -- database, koneksi, versi skema, cache, log audit, backup, dan notifikasi. Tautan ini hanya aktif untuk peran admin; peran lain tetap melihat spidomernya, dengan keterangan bahwa detail lengkap berada di halaman admin.

Kenapa ada dua tampilan? Spidometer di dashboard pengurus adalah ringkasan cepat (jantung yang sama dengan halaman admin -- satu sumber data, dua tampilan). Jika jarum kuning/merah, admin memeriksa 7 kartu detail; pengurus cukup melihat apakah perlu bertindak atau tidak.

4. Kapan Angka Ini Berubah?

Spidometer dihitung ulang setiap kali halaman dashboard dibuka atau dimuat ulang (tanpa tombol khusus). Angka yang tampil adalah kondisi saat itu. Jika database sedang bermasalah, spidometer akan merah dan halaman lain tetap berjalan normal; spidometer itu sendiri yang melapor, bukan sistem yang rusak.

5. Ringkasan Cepat

SituasiYang Anda Lihat
Semua sehatSkor 100, jarum hijau di ujung kanan, semua baris hijau.
Backup sudah lama (lebih dari 30 hari)Baris Backup kuning; skor turun 10.
Database lambat (500-2000 ms)Baris Database kuning ("LAMBAT"); skor turun 10.
Database tidak terjangkauSkor 30, jarum merah; baris Database "GAGAL". Hubungi admin.
Push belum diaktifkanBaris Push "PUSH OFF" kuning; notifikasi in-app tetap normal.
